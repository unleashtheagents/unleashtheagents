# `uta` — Unleash the Agents

<img align="right" width="96" height="96" src="https://unleashtheagents.ai/icon-512.png" alt="uta icon" />

**[`uta`](https://github.com/unleashtheagents/uta)** is an open-source (MIT) static Go CLI agent orchestrator that plans with one model and fans subtasks out in parallel across cloud and local coding agents:

- **NVIDIA Nemotron 3 (Ultra / Super / Nano / Super-VL)** on **Nebius Token Factory** (`uta nebius`) with real-time **Tavily** web grounding
- **Claude Code (`claude`)**, **Google Antigravity (`agy`)**, **Gemini CLI (`gemini`)**, and **Codex (`codex`)**
- Interactive agent shell (`uta shell`) with `/` skills (`.agents/skills`, `.claude/skills`), `!` local bash execution, trajectory recording, and native **Warp Terminal** OSC 777 session notifications

```bash
brew install unleashtheagents/tap/uta
```
